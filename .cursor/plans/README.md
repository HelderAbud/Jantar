# Planos — Convite Jantar

Planos aprovados para tarefas **Normal** ou acima (Helder Method v1.2).

## Convenção de nome

```text
plan-YYYY-MM-DD-assunto.md
```

Exemplo: `plan-2026-07-05-ajuste-tela-final.md`

## Conteúdo mínimo

1. Objetivo e trilha (Simple / Normal / Complex / Hotfix)
2. Contrato afetado (telas, textos, interações)
3. Fatias verticais com critério de pronto
4. Validação manual (mobile, link publicado)
5. Riscos e gates humanos
