# Convite Jantar ✨

Convite interativo estilo iPhone — mini app HTML para convidar Alexia a um jantar.

**Link:** https://helderabud.github.io/Jantar/

## O que é

Experiência mobile com 6 telas: bloqueio → IA analisando → resultado → missão → escolha do jantar → confirmação.

## Stack

- HTML + CSS + JavaScript (arquivo único: `index.html`)
- GitHub Pages

## Desenvolvimento

```bash
# Local
python -m http.server 8080
# Abrir http://localhost:8080
```
